# একটুখানি

বাংলায় আঁকা, খেলা আর দৈনন্দিন ছোট কাজের **২০টি টুল, একটি Next.js অ্যাপ**। প্রথম পাতায় হিরোর পরেই সবগুলো দেখা যায়; ধরন বেছে তালিকা ছোট করা যায়। নিবন্ধন, বিজ্ঞাপন, ট্র্যাকার বা ডেটাবেস নেই।

## চালানো

Node.js ২২ ও npm ব্যবহার করুন। এই ফোল্ডার থেকে:

```sh
npm ci
npm run dev
```

খুলুন [একটুখানি](http://127.0.0.1:3100/)। সব টুল একই সার্ভারে, আলাদা রুটে চলে।

```sh
npm test
npm run typecheck
npm run build
npm start
```

অ্যাপ চালু রেখে অন্য terminal-এ `npm run check:pages` দিলে ৬৩টি পাতা, বাংলা metadata, canonical, দৃশ্যমান FAQ ও JSON-LD-এর মিল, ভেতরের লিংক, ছবি, ফন্ট, robots, sitemap এবং ৪০৪ পরীক্ষা করা হয়। অন্য ঠিকানা পরীক্ষা করতে `SITE_CHECK_ORIGIN` দিন।

## কোডের গঠন

```text
app/                  একটিমাত্র Next.js routing, metadata, robots ও sitemap
  <slug>/             প্রতিটি টুলের সরাসরি রুট
  [tool]/             নিয়ম ও গোপনীয়তার সাধারণ page template
components/           প্রথম পাতার হিরো, তালিকা, ফিল্টার ও ব্র্যান্ড
lib/                  টুলের তালিকা, কনটেন্ট ও ব্র্যান্ড
shared/               ফন্ট, সাধারণ UI, SEO, PNG export ও পরীক্ষা
tools/<slug>/         প্রতিটি টুলের নিজস্ব UI, হিসাব, ডেটা, লেখা ও পরীক্ষা
public/               ফন্ট (লেখা: Noto Sans Bengali, শিরোনাম: Baloo Da 2, দুটোই OFL), লাইসেন্স, preview ও social image
research/             গবেষণা; `trends-2026-10.md` (অক্টোবর ২০২৬-এর ট্রেন্ড, ভাইরাল লুপ, SEO) ও `bangla-voice-guide.md` (লেখার নিয়ম: সবসময় "তুমি", স্বাভাবিক বাংলা)
artifacts/            পরীক্ষার ছবি, PDF ও নথি
```

`projects/`-এর তেরোটি স্বতন্ত্র Next.js অ্যাপ সরিয়ে তাদের মূল কোড `tools/`-এ আনা হয়েছে। পুনরাবৃত্ত package/config/layout/guide/privacy ফাইলের জায়গায় একটি অ্যাপ ও সাধারণ page template আছে। প্রতিটি টুলের CSS তার wrapper-এর মধ্যে সীমিত; প্রিন্টের জন্য আলাদা named page আছে। তাই এক টুলের CSS অন্যটিতে লাগে না। সময়ভিত্তিক আয়োজনের পাতা request-এর সময় render হয়।

## প্রকাশ করা

নিজের আসল HTTPS origin দিয়ে `SITE_URL` বসিয়ে build করুন। একটি origin-এই সব রুট প্রকাশ হবে। এই মান ছাড়া স্থানীয় preview `noindex` থাকে এবং sitemap খালি থাকে। canonical বা কোনো কাল্পনিক public domain যোগ করা হয় না; social image-এর স্থানীয় ঠিকানা `http://127.0.0.1:3100`।

```sh
npm run build
npm start
```

প্রকাশের পরে সেই origin দিয়ে `SITE_CHECK_ORIGIN` ও একই `SITE_URL` সেট করে `npm run check:pages` চালান। Google Search Console-এ sitemap দিন। FAQ schema থাকলেই বিশেষ search display পাওয়া যাবে—এমন নিশ্চয়তা নেই।

## তথ্য ও সীমা

- বাজার নোট ও শেষ তারিখে ব্যবহারকারী নিজে সংরক্ষণ করলে আলাদা localStorage key-তে তথ্য থাকে। পুরোনো আলাদা পোর্টে রাখা তথ্য নতুন origin-এ নিজে থেকে আসে না; পুরোনো ব্রাউজারের তথ্য মোছা হয়নি। অন্য টুলের কাজ পাতা বন্ধের আগে ডাউনলোড, কপি বা প্রিন্ট করে রাখতে হয়।
- ছবি ব্রাউজারেই তৈরি হয়। সমর্থিত ডিভাইসে আগে শেয়ারের ফাইল তৈরি, তারপর নতুন বোতামে চাপ দিয়ে শেয়ার করা যায়। কোনো স্বয়ংক্রিয় পোস্ট করা হয় না।
- কাগজের পাখির এক পাতার A4 ছক পরীক্ষা হয়েছে; বাস্তবে কেটে জোড়া দেওয়ার পরীক্ষা হয়নি। আলপনা এক পাতার আঁকার গাইড, বহু পাতার কাটআউট স্টেনসিল নয়। প্রিন্টের মাপ calibration রেখা দিয়ে মিলিয়ে নিতে হয়।
- ছবিখাতার শব্দ ব্যবহারকারীর দেওয়া; কোনো যাচাইকৃত আঞ্চলিক অভিধান নয়। সবুজ কোণ কল্পিত দৃশ্য; বাস্তব গাছের উপযোগিতা বা ভার বহনের ক্ষমতা যাচাই করে না।
- মেট্রোর ভাড়া স্থির সরকারি সারণি থেকে হিসাব করা হয়; সরাসরি হালনাগাদ নয়। উৎস ও দেখা হওয়ার তারিখ টুলের পাতায় আছে।
- ভালো কাজ ও অবসরের পাতায় যাচাইকৃত আয়োজনের তালিকা এখন খালি। ব্যক্তিগত পরিকল্পনা কোনো নিশ্চিত আয়োজন নয়। নতুন আয়োজন যোগ করলে উৎস, মেয়াদ, বাতিলের অবস্থা ও সম্পাদকীয় যাচাই রাখতে হবে।
- এখনো public deployment বা বাস্তব ব্যবহারকারীর pilot করা হয়নি।

## নতুন ইন্টার‌্যাকশন ও গবেষণা

আলপনায় হাতে আঁকা রেখা, ছোট্ট পাড়ায় বস্তু টেনে সরানো এবং সবুজ কোণে গাছ সরানো যায়। আঁকার ও সাজানোর কাজে ৫০ ধাপ পর্যন্ত আগের অবস্থায় ফেরার সুবিধা আছে। সাতটি নতুন টুলের গবেষণা, উৎস ও সীমা `research/interactive-expansion/`-এ আছে। ধারণার সাংস্কৃতিক পরিচিতি বা অন্য পণ্যের উপস্থিতিকে এই সাইটের চাহিদা বা ভাইরাল হওয়ার প্রমাণ ধরা হয়নি।

ছবি জোড়ায় সর্বোচ্চ চারটি জেপিজি/পিএনজি/ওয়েবপি ছবি, প্রতিটি ৮ মেগাবাইট ও ৩০ মেগাপিক্সেলের মধ্যে। ব্রাউজারে পড়ার পরে বড় দিক ১৬০০ পিক্সেলের মধ্যে নামিয়ে নতুন ছবি তৈরি হয়। আপলোড সার্ভার নেই। কাজ পাতা বন্ধের আগে ডাউনলোড করে রাখুন।
